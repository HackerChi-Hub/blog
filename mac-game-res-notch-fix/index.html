刘海屏玩游戏画面被挡？ 两条命令搞定

一个开源脚本，解决苹果懒得管的烦恼。

2026-07-06 · 黑粉科技 原创

先说痛点：刘海是怎么毁掉一局游戏的

事情是这样的。换了台 MacBook Pro 16 寸，M 系列芯片性能猛，屏幕 120Hz ProMotion 丝滑，兴冲冲装了个游戏准备爽一把。全屏一进去——好家伙，画面正中间顶部，硬生生少了一块。

那块少掉的区域就是刘海。平时看网页、写文档它还算安分，但游戏全屏的时候它就开始捣乱了：小地图的边缘可能被切掉一截，血条最右边那格可能看不见，最惨的是 FPS 游戏里敌人蹲在刘海正下方你根本发现不了。这不是夸张，是每个 MacBook 刘海屏玩家都经历过的真实场景。

更烦人的是，苹果压根没给一个像样的解决方案。系统设置里倒是藏了一个能避开刘海的「缩放分辨率」，但要点进系统设置、显示器、分辨率、选缩放、再挑一个不那么模糊的档位——前后四五层操作。玩完还得原路切回去，不然日常用着别扭。一晚上来回切几次，游戏的心情都没了。

⚠️
刘海看视频时是苹果的设计美学，玩游戏时就是画面中间一个吞视野的黑洞。

game-res：两条命令让它消失

实在被搞烦了，就写了个脚本叫 game-res。思路很直接：玩游戏前敲 game-on，整个画面自动往下挪一截，刘海区域变成一条干净的黑边，游戏画面完整不被挡；玩完敲 game-off，切回默认的 Retina 分辨率，一切照旧。

原理说穿了很简单。16 寸 MacBook Pro 的默认逻辑分辨率是 1512 乘 982，刘海就卡在顶部菜单栏正中间。game-on 会切到 1512 乘 945 这个档位——高度刚好少 37 个像素，而这 37 像素恰好就是刘海的高度。于是整个工作区整体下移，刘海被一条黑边盖住，画面干干净净。

💡
不需要装那些花里胡哨的刘海屏蔽软件，不改系统文件，不重启。命令敲下去瞬间切换，体验丝滑。

30 秒装好，复制粘贴就完事

安装只需要一个前提：你装了 Homebrew。Mac 用户基本都有，没有的去 brew.sh 装一下，一分钟的事。然后三条命令搞定：

📦
安装: git clone https://github.com/HackerChi-Hub/mac-quick-scripts.git cd mac-quick-scripts ./install.sh

安装脚本会自动帮你装好依赖 displayplacer，把 game-res 放到命令行路径里，再创建好 game-on 和 game-off 两个快捷命令。装完直接就能用，不用配置环境变量，不用改 shell 配置文件。

日常使用就三条命令，看一眼就记住了：

命令干了什么什么时候用
game-on画面下移避刘海 + 关热区玩游戏前敲一下
game-off切回默认分辨率 + 开热区玩完敲一下
game-res看当前是什么模式忘了的时候敲

顺手把热区也关了，告别误触

玩游戏时还有个特别恶心的体验：鼠标狂甩走位，一不小心碰到屏幕四个角落的其中一个——哗，调度中心弹出来了；或者突然切到桌面；又或者通知中心从右侧滑出来。游戏直接被打断，等你切回去角色可能已经凉了。

所以 game-on 在切分辨率的同时，顺手把四个热区全关了。左上调度中心、右上通知中心、左下桌面、右下启动台，全给你摁住。玩完 game-off 会自动恢复你原来的热区设置，一个不少。一条命令同时干掉「刘海挡画面」和「角落误触」两个游戏时的痛点。

💡
脚本做了幂等处理。手滑多敲了一次 game-on 也不会怎样，它检测到已经是游戏模式就会直接跳过，不会让屏幕和 Dock 闪来闪去。

开源了，MIT 协议随便用

脚本已经开源到 GitHub，MIT 协议，随便用随便改。整个脚本一百来行 bash，干干净净：核心就是调 displayplacer 切分辨率，加 defaults write 控制热区，再做了个幂等检测防止重复切换时屏幕闪烁。没有依赖注入，没有后台常驻，跑完就退出，干净利落。

如果你用的不是 16 寸 MacBook Pro，避刘海的分辨率数字可能不一样。脚本顶部留了配置项，改两个数字就行，不知道支持哪些分辨率就敲一条 displayplacer list，所有可选模式都会列出来：

🗂️
自定义分辨率: GAME_RES="1512x945" # 你的避刘海分辨率 DEFAULT_RES="1512x982" # 你的默认分辨率

选一个高度比默认矮一截的就是避刘海的档位。14 寸的 MacBook Pro 数字会不一样，照着改就行。

这是 mac-quick-scripts 这个仓库的第一个脚本。后续如果还有其他 Mac 上「苹果不给你解决但你天天受折磨」的小烦恼，也会往这个仓库里加。如果你也有好用的效率脚本，欢迎提 PR。

📌
一句话总结 苹果不给你解决的烦恼，自己动手丰衣足食。game-res 两条命令告别刘海挡画面，30 秒装好，MIT 开源。GitHub 搜 HackerChi-Hub/mac-quick-scripts，或者看评论区链接。觉得好用给个 Star，这是对开源作者最大的鼓励。

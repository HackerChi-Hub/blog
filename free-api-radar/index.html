二、主力稳用平台接入细节与避坑实证

1. Groq（海外速度之王 · 免绑卡）

　　只要你本地开着国际网络，Groq 依然是目前响应最干脆的免费主力。用邮箱、Google 或 GitHub 注册就能直接拿 Key，不需要绑信用卡。本期本机连续 4 次请求 qwen/qwen3.8-27b（含中文多段备份方案生成）全部在 409ms–1125ms 内返回，openai/gpt-oss-120b 也在 643ms 内跑通，官方免费限额维持 30 RPM / 1,000 RPD / 8,000 TPM。

from openai import OpenAI

client = OpenAI(api_key="<GROQ_API_KEY>", base_url="https://api.groq.com/openai/v1")
resp = client.chat.completions.create(
    model="qwen/qwen3.8-27b",
    messages=[{"role": "user", "content": "用三句话讲清本地备份原则"}],
)
print(resp.choices[0].message.content)

2. Google Gemini API（认准 Flash-Lite 与 Embedding 2 · 注意隐私条款）

　　11 月 Google 推出 Gemini 4 系列后，旗舰 Gemini 4 Carbon / Argon / Neon 全部锁死在付费层，免费层保留给 Gemini 4 Hydrogen 限流档以及 gemini-3.5-flash-lite、gemini-embedding-2 等型号。本期实测 gemini-3.5-flash-lite 与 gemini-embedding-2 均 4 次全绿通过（621–1387ms），而 gemini-3.6-flash 和 gemma-4-31b-it 在晚高峰多次撞上 HTTP 503 High Demand。另外务必注意：AI Studio 免费层默认会将输入输出用于改进 Google 产品，写公司私有代码别往免费层塞。

3. 智谱 BigModel & 魔搭 ModelScope（国内直连免代理双保险）

　　不想配国际网络代理的国内开发者，优先看这两家正规大厂入口（都需要 +86 手机号验证码 + 国内实名认证，都不需要信用卡）：

  • 智谱开放平台（查看智谱免费模型文档）：永久免费主力已经从下线的 GLM-4.5-Flash / GLM-Z1-Flash 升级到了 GLM-4.7-Flash（30B 参数、200K 上下文、支持工具调用与深度思考） 和多模态 GLM-4.6V-Flash，大陆直连延迟约 137ms，且协议明确默认不拿用户 API 数据训练模型。注意别把名字写成收费的 GLM-5.3-Flash 或 GLM-5.4。
  • 魔搭社区 API-Inference（查看魔搭 API-Inference 文档）：绑定已实名的阿里云账号后，每天登录可领 200+50 短期魔粒（约合每天免费调用 125–500 次），能直接用 OpenAI 兼容格式调 Kimi-K3.1-Pro、Qwen3.8-27B 等大尺寸模型，大陆直连仅 84ms。

4. OpenRouter（全站仅剩 10 款零价文本模型 · 必须防单点限流与下架）

　　对比 8 月份的 22 款零价模型，2026 年 11 月 27 日实取 /api/v1/models 全站 477 个模型里只剩 10 个零价文本对话变体（外加即将于 11月28日 下架的 Recraft 生图等少量非文本条目），而且全部 10 款文本模型都只有单一上游供应商承载（eps=1）。本期实测 nvidia/nemotron-3-ultra-550b-a55b:free（1M 上下文）连续 4 次任务全部 200 OK 通过，但 google/gemma-4-26b-a4b-it:free 连发第 2 次立刻弹 429，上月还能用的 nemotron-3-super-120b:free 则已 404 转收费。

from openai import OpenAI

client = OpenAI(api_key="<OPENROUTER_KEY>", base_url="https://openrouter.ai/api/v1")
resp = client.chat.completions.create(
    model="nvidia/nemotron-3-ultra-550b-a55b:free",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)

三、零注册免密接口与已取消免费层的排雷实证

1. 免注册免 Key 应急双口：OVHcloud 与 Pollinations

  • OVHcloud AI Endpoints（查看官方目录：OVHcloud AI Endpoints，接口基址为 /v1）：真真正正连账号都不用建、中国大陆直连 1366ms 可通。本机免 Key 实测 Qwen3.8-27B 与 bge-m3（1024 维向量）首轮直接 200 OK 出结果，但匿名单 IP 连续突发第 2–3 次即返回 HTTP 429 API rate limit exceeded（冷却约 49 分钟），只适合临时单次测连通。
  • Pollinations（查看官方文档页：Pollinations）：同样免注册免 Key 可直连，但 11 月底匿名层限速收紧至 单 IP 每 45 秒最多 1 次回复，连发第 3 次即返回 HTTP 402 FREE_LIMIT（前往 申请免费密钥：Pollinations 控制台 领免费 Key 可提额）。

2. 三大旧神站免费 API 已成历史（别再白费功夫注册）

  • Mistral AI：官方 查看 Mistral 用量与限制文档 已写死 Free mode 不含 API 访问权限，建 API Key 必须绑卡激活按量计费。
  • Hugging Face Inference Providers：官方 查看 Hugging Face 推理定价页 列明 Free Users 月赠额度为 None。
  • 硅基流动旧号 402 提醒：官方 查看硅基流动限流文档 仍保留实名免费 L0 模型，但若账户余额状态异常或误选 Pro/ 前缀同名模型会返回 HTTP 402 / 30001。

四、把稳用路线一键收进「黑粉盒子 HyphenBox」与本地兜底

　　既然单家免费接口随时可能改规则、限流 429 或下架旧型号，最稳的做法就是不要在业务代码里硬编码某一家免费模型：

  1. 云端免费聚合路由：打开 下载与更新：黑粉盒子 HyphenBox（GitHub 发行页）（v1.0.7 客户端已支持自动接收本期签发的 2026.11.27.1 最新目录，无需重装软件），把你自己的 Groq、Gemini、智谱或 OpenRouter Key 留在本地钥匙串里，对外暴露一个统一的本地 OpenAI 兼容网关，遇到某家 429 自动冷却切备胎；
  2. 本地离线多模态与大模型兜底：涉及绝对不能上云的私有代码、语音转写与生图生视频，直接配合 下载与更新：方寸智匣 LocalBrain（GitHub 发行页） 与本机 Ollama / MLX 离线跑通，一分钱 API 账单都不用付。

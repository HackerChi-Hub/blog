2026 年 10 月 31 日更新：三平台 1.0.5

Windows x64 的 EXE/MSI、Linux x64 的 AppImage/DEB/RPM 与 Mac 通用包统一更新到 1.0.5。黑粉盒子继续提供免费 API 雷达、本机密钥保险箱、真实模型核验与本地兼容接口。

这版移除了遮挡内容的底部固定步骤栏，步骤编号保留在导航和关键按钮。模型页按“拉取 → 加入免费 → 核验”操作，按钮按内容宽度排齐；接入页按需展开“开始使用”，首页合并重复数字和说明，用量与诊断按需查看。

DeepSeek Harness 仍是首选接入方式，支持备份后写入、保留原配置及撤销。首次连接后重启 Harness 并建立新会话。OpenCode、Cline、Roo Code、Continue、Codex CLI 和通用兼容客户端按选择显示手动配置，示例默认 free；不会自动改写这些 Agent 的配置。根据 Cursor 当前网络方式，移除了填入本机地址即可接入的旧指引。

手动配置预览保持本机令牌遮罩，主动复制时才读取令牌，轮询快照不再携带手动配置令牌。平台密钥保存在本机系统凭据存储，请求由电脑直接发给所选提供商。

Windows 使用本机 MSVC 构建，Linux 使用 WSL Ubuntu 22.04；两端完成核心与桌面模块回归，AppImage 在隔离数据目录检查启动、目录验签与接口鉴权。公开截图保留实际 Mac 安装版的版本及日期。本轮没有新增上游模型、Agent 工具任务或自动换路的真实调用结论，1.0.4 的调用验收仍按历史版本标记。

free 只尝试合格且已核验的免费路线，auto 可能使用已添加的自费路线。Windows/Linux 使用内置签名目录，在线目录服务需另行配置；Linux 密钥保险箱需要桌面 Secret Service。更新器签名不等于 Windows 商业代码签名或 Apple 公证。用量是本机记录，估值并非平台账单；免费额度及账户条件以提供商为准。

提示 黑粉科技

提示 一句话：黑粉盒子把网上散落的免费大模型 API 收进一个本地接口。你用自己申请的 Key，它负责核验模型能不能用，然后变成一个地址填进 Cursor、Cline、OpenCode。早期目录收录 103 家；候选平台的端点探测只提供申请线索，是否真的能生成回答仍需用自己的 Key 验证。

▍免费的 API 其实很多，难的是「哪个现在还能用」

想白嫖大模型 API 的人都干过同一件事：搜一份免费清单，挨个点进去申请，然后发现一半链接已经死了，剩下一半额度早改了，好不容易申请下来的 Key 填进客户端还报错——不是不支持工具调用，就是上下文对不上。一圈折腾下来两三个小时，真正能用的没几个。

问题不在于免费资源少，而在于没人替你持续验证。清单是某个人某一天整理的，之后就不动了；而免费额度这种东西，是会变的。

▍它做的事：把免费池收进一个本地接口

装上之后你会看到两个数字：17 家已核验、86 家待核验。已核验的那批有官方证据和最后复测日期，额度、申请条件、接口地址都写清楚了，可以直接照着申请。

▍每家的额度、门槛、地址，全摊开写

这一页是我最想让人先看的。不是「某某家有免费额度」这种模糊说法，而是具体到：带 :free 后缀的模型每分钟 20 次、每天 50 次；需不需要信用卡；要不要实名；额度按天重置还是按分钟滚动。这些正是决定你要不要花十分钟去注册的信息。

这版又往前推了一步：卡片里能直接展开免费模型清单。比如硅基流动的官方 L0 免费档 16 个模型——对话、推理、OCR、翻译、向量、图像、语音全列出来，每个带官方限速（RPM/TPM）。每条都标着核对日期：免费档随时会变，日期比清单本身更重要。目前清单共 22 条，只收两种出处——官方文档页，或我自己真实调用过。

▍早期候选记录：端点存活不等于真实可调用

社区清单里还有一大批平台，我没法逐家申请 Key 去试。但不用 Key 也能确定三件事：域名还活着吗、说不说 OpenAI 协议、是不是只差一把 Key。

实测结论 家数 对你意味着什么
端点存活 + OpenAI 协议 + 只差一把 Key 68 家 值得去官网申请
公开来源里查不到接口地址 15 家 只有名字，暂时用不上
路径不对 12 家 地址过期或改版
连不上 6 家 超时或域名解析不了
能连上但不说 OpenAI 协议 1 家 要专门写适配器

提示 还有一条对国内用户特别实用的信息：这批实测每天在一台树莓派上重跑，而它就在国内网络里。于是顺带得到「挂不挂代理」——本轮 51 家国内直连可用、30 家需要代理；68 家能用的里只有 3 家要挂代理。

▍你的 Key 只存在自己电脑里

这点我想说清楚：黑粉盒子不分发、不交换、也不上传任何人的 Key。你申请的密钥写进 macOS 系统钥匙串，提示词和模型回答也不经过我的服务器——它只是一个跑在你电脑上的转发程序。

目录里没收录的平台也能用。在同一页底部填上接口地址，顺手把 Key 也填了，它会一次走完「保存地址 → 存 Key → 拉模型列表 → 核验前几个」，不用你在几个页面之间来回跳。

提示 这里的免费 Key 只指你从官方渠道自行领取的凭据。泄露密钥、共享账户、轮换 Key 池、绕额度中转站，一律不收录、不测试。

▍只有真跑通过一次的模型，才会出现在列表里

拉到模型列表不等于能用。所以每个模型都要用你自己的 Key 真发一次请求，通过了才进入本地接口。这一步顺带把两件事记下来：上下文有多大、支不支持工具调用。

第二件尤其重要。Cursor、Cline、OpenCode 这类客户端每次请求都会带工具，模型不支持的话第一句话就失败。我这台机器 99 个可用模型里 81 个支持工具——列表里直接标出来，省得你一个个试。

▍一键接进 Cursor、Cline、OpenCode

最后一步最简单：把这两行填进客户端就行。所有平台的模型都在同一个地址下，切换模型不用再改 Base URL 和 Key。

Base URL: http://127.0.0.1:17688/v1
API Key:  在「一键连接」页点「显示令牌」取

▍选 auto，就不用再猜哪个模型现在能用

这是这版最重要的新功能。起因是我自己的实测：同一个 62,959 token 的请求，nova-lite 直接跑通，claude-3-haiku 只允许 26786 tokens，aion-2.0 只允许 7228，claude-opus-4.6 只剩 1339。这个数字是「余额 ÷ 模型单价」——所以「哪个能用」不是模型属性，是价格的倒数，而且每天在变。

既然规律确定，就不该让人一个个试。模型列表第一项现在是 auto：带工具的请求只挑支持工具的模型；上下文必须装得下这次的 prompt；同等条件下标价越低越优先；你标成自费的 Key 一律排最后——白嫖工具不该默认帮你花钱。一键连接写 OpenCode 配置时也会把默认模型设成 auto（你自己设过的不动）。

提示 配套的还有可用度分级：每条路由按「模型能力 × 这把 Key 当下额度 × 你的实际工作量（取实测单次最大 52075 tokens）」标成三档。我这台机器现在是：可跑 agent 28 条、额度不够 57 条、限流帽子不够 5 条、仅纯对话 7 条。额度和限流都是从上游报错里学的（比如 Groq 明说每分钟 8000 tokens），不硬编码任何一家。

▍白嫖成果：到底给你省下了什么

首页底部有块累计面板。我自己这台机器目前是：横跨 4 家提供商的 93 个模型、230 次真实调用，实付 $0.00。按各家官方公布的标价折算，这些用量值 $0.21。

$0.21 不好看，我也没把它放在主位——我用的都是便宜模型，金额讲不出规模，token 量和模型数才讲得出。而且折算只按提供商自己公布的标价算，查不到价格的部分明确标注「未计入」，宁可把成果说小，也不拿猜的单价凑数。

提示 还有一条更要紧的：自费的 Key 不算白嫖成果。软件支持你填任何平台的任何 Key，包括自己付钱的，所以每把 Key 都可以在保险箱里声明是免费额度还是自费。我自己就有 1 家是自费的（15 万 tokens、18 次），它们单列在面板下方，明确写着「不计入白嫖成果」。不区分的话，这块面板就会把你自己花的钱算成白嫖，还在标题上写「实付 $0.00」——那是替你说一句不成立的话。

▍为什么做这个，以及最难的一段

起点很实际：我自己每天在几个客户端里切免费 API，受够了反复翻定价页和试错。想找个现成的工具，发现要么是纯清单不验证，要么是要把 Key 交给别人代管——前者不解决问题，后者我不放心。

做起来最难的不是转发请求，是判断「能用」。一开始我以为接口返回 200 就算通过，后来发现有些平台的模型列表是公开的、真发对话就要 Key；还有些「模型」根本不是聊天模型——问它「用一句话解释什么是 API」，回的是一串小数，因为那是个内容分类器。这类东西以前会一路混进可用列表，等你在客户端里选中才失败，而且失败原因看着毫不相干。

所以现在的判据是死磕出来的：必须真发一次对话请求，回复得像句人话才算数。听起来笨，但它是唯一能让「列表里的模型点开就能用」的办法。

▍会往外发什么数据

软件默认开启匿名使用统计，每个自然日最多上报一次，界面里随时可以关掉。一个主打「密钥不出本机」的东西，更没资格在这件事上含糊，所以说明白：

  • 只上报五个字段：匿名设备哈希、版本号、操作系统、CPU 架构、日期。

  • 不上报 API Key、提示词、模型回答、用量数字、文件路径、用户名和 IP。

提示 它现在的阶段是 正式推出 · 正式迭代，正式版从 1.0.0 起步，三平台安装包均已公开。各个平台、模型和账户仍有自己的限制。免费额度随时会变，软件提供更新线索与本机核验，不能保证注册时额度仍在，也不能保证每条请求都成功。

提示 免费会变，记录不能丢

黑粉盒子不是一张看起来很满的免费清单，而是一套持续更新、保留核验证据的本地 API 雷达。早期收录和网络探测数字保留为历史记录；真正选模型时，要看最新官方条件和你自己账户的真实核验结果。

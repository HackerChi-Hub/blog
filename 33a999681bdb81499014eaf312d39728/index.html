我用Claude Code一个下午搭了个AI新闻收集器，GitHub Pages免费部署

2026/04/065 分钟
分类：技术分享
标签：#AI#人工智能#新闻

信息焦虑的本质，不是新闻太少，是整理太难。

每天睁眼就是 AI 领域的各种爆炸新闻——哪个模型又发布了，哪家公司又被收购了，哪个开源项目又登上热榜了。但大部分人的处理方式，要么是刷到哪算哪，要么是订阅一堆 Newsletter 然后全部已读。

真正有用的，是一个能自动帮你收集、分类、翻译、提炼的工具。

这次我直接用 Claude Code 做了一个——全程不到一个下午，GitHub Pages 零成本部署，代码完全开源。

它能做什么

最终产品叫 AI 新闻雷达（AI News Radar）：

  • 自动从多个 RSS 源抓取新闻，本次跑出 287 篇文章
  • 用 AI 对每篇文章生成中文摘要 + 关键词分类
  • 按类别（AI、科技、安全、研究……）自动归档
  • 每天定时自动更新，部署在 GitHub Pages，完全免费
  • 还有一个「今日最重要 10 条」速报功能，帮你直接抓重点

怎么做到的

第一步：跟 Claude Code 说需求

我只打了一句话：

制作 AI 新闻收集器，部署在 GitHub Pages，要求免费。

Claude Code 直接输出了完整的技术架构表，然后它自己去做了一件我没想到的事——主动调研了三家免费 LLM API 并输出对比表：

API免费额度速度翻译质量
Gemini Flash-Lite每分钟 15 次快好
Groq每天限量极快好
Cerebras有限额快一般

最终方案：Groq 作为主力（速度最快），Gemini 备用。

第二步：Claude Code 开始写代码

任务清单自动出现在终端，我几乎没有手动写一行代码，全程在旁边看着它写，偶尔提一个新需求。

第三步：第一次跑通

代码写完，git push 上去，GitHub Actions 自动触发，第一次就抓到了 88 篇文章，网站上线了。

第四步：踩了一个坑——API Key 暴露

接入 Gemini API 的时候，我直接把 API Key 写进了代码——Claude Code 立刻给我发出警告：

⚠️ API Key 不能明文提交到 GitHub，否则会被自动扫描工具检测并失效。

它随后引导我把 Key 配置到 GitHub Actions Secrets，再通过环境变量注入。这一步如果不是它提醒，我可能就直接推上去了。

第五步：功能增强

基础版跑通之后，我继续加需求：

  1. 中文翻译：每篇英文新闻自动翻译标题和摘要
  2. 关键词分类：AI / 开源 / 安全 / 行业 / 研究，自动打标
  3. 今日速报：让 AI 从 287 篇中挑出最重要的 10 条，生成「AI 速报」

每次加需求，Claude Code 直接实现，我只需要验收。

最终效果

  • 287 篇文章，覆盖主流 AI 资讯来源
  • 中英双语摘要，关键词分类清晰
  • 「今日最重要 10 条」一键看懂当天 AI 动态
  • 网站已上线，每天自动更新

整个过程：一个下午 + 一段视频。

几点感受

1. AI 编程的门槛在快速消失

我不需要记住所有 API 文档，不需要知道 GitHub Actions 的 yaml 语法，不需要会 React 组件怎么写。只要能把需求描述清楚，剩下的 Claude Code 来做。

2. 但你仍然需要判断力

API Key 暴露这个坑，如果不懂基本的安全常识，Claude Code 提醒了你也可能忽视。AI 能帮你做，但你要知道它做的对不对。

3. 免费额度够用，但有上限

Groq 每天的免费额度大概能处理 200-300 篇文章的摘要，够日常使用。如果量更大，需要付费或轮换多个 key。

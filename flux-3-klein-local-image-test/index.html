四、杀手锏实测：0-1000 归一化坐标框摆位有多准？多图拼合注意哪两个坑？

　　整轮测试里最让我觉得好玩的，就是 FLUX 3 Klein 原生自带的 0-1000 归一化坐标框布局控制。以前想往成片指定角落塞一只宠物，要么得手涂局部重绘蒙版，要么靠抽卡碰运气；现在直接把整张画布横竖都当成 0 到 1000 的千分尺，在提示词末尾附一段 JSON 数组就能指哪打哪。

警告：写坐标框前必避的顺序坑：是 [上, 左, 下, 右]，不是 [x1, y1, x2, y2]！ 据 查阅 NVIDIA NIM 官方模型卡与坐标框说明，FLUX 3 Klein 的每一个 bbox 四元组顺序固定为 [top, left, bottom, right]（上、左、下、右，取值 0…1000），并且在正文里要用 <id> 把对象锚定出来。如果你按习惯写成 [左, 上, 右, 下]，左右并排的两个人会被模型直接叠成上下两层！

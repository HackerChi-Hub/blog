ScreenLex 光影词库

把你本地的电影和剧集，变成真正能复习的英语词库

黑粉科技 HyphenTech · macOS Apple Silicon · v0.2.12

你有没有过这种经历：电影看得挺爽，英语也确实听到了，但一集看完，脑子里只剩剧情，单词一个没留下。

这就是我做 ScreenLex 光影词库 的原因。它不是播放器，也不提供影视资源，而是把你本机已有电影和剧集的字幕，整理成可以复习的高级词汇、短语、双语字幕和学习记录。

❓
播放器负责让你看得舒服，ScreenLex 负责让你看完之后真的留下东西。

为什么看电影学英语总是失败

很多人都试过用电影学英语。开一部原声片，打开字幕，心里想着这次一定要练听力、学表达、积累词汇。但现实通常很扎心：

  • 剧情太好看，学习动作被剧情带走
  • 遇到生词临时查一下，查完就忘
  • 真正值得学的词，混在一堆简单词里
  • 想让 AI 解释，还要复制原句、时间点和上下文

最后，电影是看完了，英语却没有沉淀下来。ScreenLex 想接住的就是这个断点：把「看过」变成「可复习」。

它只抓「值得学」的内容

ScreenLex 不是把字幕全文丢给你，也不是随便列几十个基础词。它会从英文字幕里提取更适合中国学习者的高价值内容：高级词汇、考试词、影视短语 chunks、词根词源、原句和时间点、中文释义、例句翻译和记忆方法。

词汇分级也更贴近国内场景，不是泛泛的 A1/B2/C1，而是围绕 高考、四级、六级、考研、专四、专八、雅思、托福、GRE 组织。内置一份 14,942 词的考试分级表，纯离线、不联网、无任何凭证就能用。

逐句学习播放器：哪句不懂点哪句

内置一个逐句学习播放器（不替代你的主力播放器，只服务「逐句精听」）。右侧是整部片的台词列表，点哪句跳哪句，支持单句循环、A-B 循环、倍速、字幕偏移和进度恢复。

一键离线处理：字幕 + 生词，全程不花钱

整部片可以一键跑完，也可以拆开单独跑。

字幕功能为什么值得单独说

它处理的是影视学习里最常见的几个麻烦：没有英文字幕，用本地 Whisper 补 SRT；识别有错，用 AI 校对；想在 Infuse 看双语，生成上英下中的 .zh.ass；长剧集翻一半失败，下次从断点续跑；已经生成过的，新版会跳过不重复浪费 token。

🔧
v0.2.12 专门修了 Whisper 的循环幻觉（关闭 condition_on_previous_text + 初始 prompt + 多项阈值），缓解「I'm sorry / Yeah」这类重复空转。

AI 是增强，不是门槛

我比较喜欢的一点是，ScreenLex 没有把所有能力都绑死在 AI 上。不配置模型时，它也能用本地词库提取高级词汇、中文释义和考试标签；配置模型后，再进一步讲清语境、补例句翻译、词根词源和记忆方法。

v0.2.12 还新增「去除 AI」按钮：丢弃 AI 精讲缓存、重新离线提取，不再调用大模型。

朗读、跟读、听写都在软件里

词卡可以分别朗读「目标词」和「跟读台词」，主动复习还支持听写。用系统英文语音，可选口音、语速和循环次数。

学习闭环还包括主动回忆复习：英中互测、例句挖空、答案揭晓、四档评分和自适应复习间隔——不是看一遍就算，而是隔几天再来抽你一次。

数据全在本机，可备份可恢复

学习包、AI 详解、全局词库、复习记录和界面偏好，统一存在本机 SQLite 数据库。旧 JSON 数据首次启动自动迁移，支持完整备份与恢复；备份不含电影、字幕和模型 API Key。

目录管理与开箱自检

侧边栏负责「喂数据」和日常维护：选目录、扫描影片库、配置模型、检查更新，批量处理和任务中心也挂在这里。

第一次打开会做一轮环境自检，FFmpeg、ffprobe、mpv、MLX Whisper 和所选模型逐项检查，缺什么一目了然。

它和普通背单词软件不一样

普通背单词软件通常从词表出发：先有一个考试列表，再让你背。ScreenLex 是从你真实看过的影视内容出发——这个词为什么出现、谁说的、在哪一幕、当时情绪是什么，都和原句绑定在一起。

适合谁，又有什么限制

  • 本地有不少英文电影和剧集、平时用 Infuse 等播放器管理的人
  • 想学高级词汇，不想再被简单词刷屏的人
  • 正在准备四六级、考研、雅思、托福、GRE 的人
  • 希望学习数据、字幕处理和缓存尽量留在本机的人
⚠️
当前公开版本首先支持 macOS Apple Silicon，还没做 Apple 签名和公证，第一次打开可能提示「无法验证开发者」，需右键打开或在隐私与安全性里允许。本地 Whisper、AI 模型、OpenSubtitles 等需自行配置；不内置商业模型账号，也不提供任何影视内容或字幕资源。

## The image interface and chat interface should be connected separately

Image-based response means giving existing images to the model to understand; text-to-image generates new images; The latter may also use asynchronous tasks. The platform supports image uploads and cannot directly release free drawing options. When connected to HyphenBox, text, images, and videos each register capability and test status; a single "available" switch cannot enclose everything.

First, download the original file of the generated result and check the format, size, task object, and actions; Only use the temporary URL for collection; if the link fails, you won't even see the sample images. Services that need to queue must also save the task number, then check the original task later to avoid submitting multiple images after the timeout expires.

For commercial use, check the license for the service and specific model. The free description only applies to the cost per call and cannot automatically deduce that the material can be used in all commercial scenarios. This version has not yet reviewed the commercial license item by item.

For the rest, leave entry points for free types, and after completing the actual generated results, arrange detailed test sections for each.

## First, choose which free option you need

Designated models at zero price, like stores only offering products with event coupons for free; Cycle quotas, like monthly reissued trial coupons; Password-free services, like public queues where you can queue without a number. They address cost, trial, and access convenience respectively, and cannot add up credit units.

| Demand | Let's first look at which category | Priority checks |
| --- | --- | --- |
| Organize small amounts of text every day | Specify zero price/cycle quota | Accurate modeling, reset, speed limiting |
| Temporary verification scripts | Password-free/shared queues | Wait, fail, and output match |
| Long-term access to products | Formal services are permitted for the corresponding purpose | Quota, permissions, and failure handling |

## Turning directories into usable interfaces—how much step is needed?

First, create a key with your own account, select the exact model from the directory, and send a small task with a standard answer; Keep the status code, answer, actual model, and time spent. For example, this order question cost 3400 yuan, and the program can check directly. After mastering chat questions, test your abilities for reading, translation, and other abilities, without counting a single text answer as verified by the entire platform.

Cloudflare's Neurons are units of usage calculated by model, more like the power consumed by different appliances; not the number of requests. Vercel's points are shared wallets; As the number of models increases, wallets don't add a few more accordingly. Moda's model file pages and callable interfaces are also different, so you must find an open inference service.

> [!quote] My judgment
> First, find one entry point from the four tests that have completed similar tasks, then fill in the options according to this directory. Listing newly registered entries one by one at the end saves the time of "saving many addresses but not a single one is actually connected."

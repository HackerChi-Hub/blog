Want to know which internal features are activated when Qianwen processes a sentence? ByteDanceSeed's Cross-Layer-TopK-CLT provides a research entry point: extracting internal features from Qwen3-8B-Base and using these features to reconstruct some internal computational results. Those interested in studying internal model computations can continue reading; those who want to directly enhance chat performance do not make corresponding commitments.

## It extracts internal features, not ready-made thought statements

Officially, it is called a cross-layer transcoder, abbreviated as CLT. You can temporarily think of the internal processing process of the model as a parish sorting: parcels pass through different stations, each containing information being processed. CLT reads this information from designated positions on each layer, converts it into a set of numbered features with activation values, and then reconstructs the output of the corresponding computing module using the selected features. Here, the numbers are like shelf locations, telling you where the features are and how strong they are activated; The numbers themselves do not include a pickup slip explaining the meaning.

For this project, feature reading is the residual flow before the MLP of each feedforward computing module, officially denoted as resid_mid; The reconstruction target is the MLP output, denoted as mlp_out. Features from each layer can participate in reconstructing the MLP output of the current and subsequent layers, so the observed relationships span layer to layer and not remain confined to a single layer.

![Project Mechanism](https://hyphentech.top/obsidian-assets/2026-11-05-official-49b677f36d92/source-evidence-1-03144dbf.png)

The officially listed structure consists of 36 layers, each containing 32,768 potential features. After encoding, the program scores the activation values and decoder column norms, jointly retaining the highest 360 features across all layers. Here, TopK is cross-layer joint screening, not each layer picking the same number of features.

This organizes internal calculations into sparse feature records for further analysis. However, the official example shows feature numbers, activation values, and the shapes of reconstruction results, without providing natural language meaning for each feature. To answer exactly what a feature corresponds to, a separate verification process must be designed, and the output list cannot be directly treated as a complete model explanation.

## Choose encoding or rebuild first, then consider downloading

The number that most influences usage choice is size: the official CLT lists 94.2 billion, which is 94.2 billion parameters, using fp32 format, with a total file size of 377 GB. This reflects the scale of the codec itself, not rewriting the base model Qwen3-8B-Base to 94.2 billion, nor is it a rating for chat capability.

If the goal is simply to see which features are activated, you can choose to encode only. The official requirement is to set DECODE = False in the sample code and to skip the decoder file; The documentation states that an 80 GB graphics card is sufficient to run this encoding example. For research tasks that do not need to reconstruct output for the time being, this path is more worth checking first.

![Encoding Conditions](https://hyphentech.top/obsidian-assets/2026-11-05-official-49b677f36d92/source-evidence-2-e1fae2bb.png)

If you want to restore features to MLP output, you need a decoder. The official decoder file is labeled as 357 GB and provides a multi-card boot example using 8 processes. File size stores information, and the startup command is a sample configuration; The documentation does not provide a universal minimum video memory for complete reconstruction based on this, nor does it list runtime and cannot be directly converted to a computer's available configuration.

The operation method should also be considered separately: the attached examples use PyTorch, CUDA, and NCCL. The documentation does not provide adaptation instructions for Mac, MLX, or other backend running devices. Therefore, the weights are already open and existing computers can run directly require separate confirmation.

## After running out of the feature list, what should be accepted?

The official example uses preset sentences in the code, prints each word element to activate features, and then reconstructs them into mlp_out. A word element can be understood as a WeChat message cut into small segments by the model: one fragment may not correspond to a complete Chinese character or word. The example lists features at different layers according to these fragments, so when reading output, you need to look at the text fragment, the layer it is in, and the feature number together.

There are two settings during reproduction that can easily affect results. According to the official instructions, the activation normalization used for training has already been incorporated into the weights, so do not use the scaling factor in factors.safetensors; The base model should also use fp32 to maintain activation accuracy consistent with training. There is also outlier handling: when the norm of a correlation vector in any layer reaches 20 times the mean of that layer, the corresponding word element is discarded, and the first word element in the official example is marked as an outlier.

![Operating Precautions](https://hyphentech.top/obsidian-assets/2026-11-05-official-49b677f36d92/source-evidence-3-68012252.png)

Therefore, acceptance can proceed along the actual output: whether the code produces element-by-word and layer-by-layer feature records, whether outliers are handled according to rules, and whether the expected output is obtained after enabling reconstruction. To further judge whether the reconstruction is good, it is necessary to compare the reconstruction value with the original MLP output of the base model. The page shows the shape of the reconstruction result but does not provide a reconstruction error score; The shape was successfully printed, but only the checks of the runway process were completed.

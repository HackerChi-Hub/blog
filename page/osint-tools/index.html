一般搜索

下面是一些用户使用的主要搜索引擎的简介：

  • Advangle - 帮助用户在互联网上找到他们需要的信息，包括图像、视频、新闻和博客等。
  • Aol - 一个门户网站，提供新闻、娱乐、邮件、搜索等服务。
  • Ask - 全球第十大搜索引擎，提供网页搜索、垂直搜索、图片搜索等功能。
  • Bing - 微软公司开发的搜索引擎，提供网页搜索、图片搜索、视频搜索等功能。
  • Brave - 一个基于隐私保护的搜索引擎，不会记录用户的搜索记录或个人信息。
  • DuckDuckGo - 一个隐私保护的搜索引擎，强调保护用户的隐私和匿名性。
  • Gigablast - 为合作伙伴网站提供大规模、高性能、实时的信息检索技术和服务。
  • Goodsearch - 一个慈善搜索引擎，将一部分广告收入捐赠给慈善机构。
  • Google 搜索 - 全球最受欢迎的搜索引擎，提供网页搜索、图片搜索、新闻搜索等功能。
  • Instya - 一个元搜索引擎，同时搜索多个搜索引擎的结果。
  • Impersonal.me - 一个隐私保护的搜索引擎，不会记录用户的搜索记录或个人信息。
  • Lycos - 一个门户网站，提供搜索、电子邮件、网站建设等服务。
  • Mojeek - 一个隐私保护的搜索引擎，强调保护用户的隐私和匿名性。
  • Search.com - 一个元搜索引擎，同时搜索多个搜索引擎的结果。
  • SurfCanyon - 一种实时上下文搜索技术，可以观察用户行为以“即时”消除意图歧义，然后自动将相关结果带到第一页，否则这些结果可能会被埋没。
  • Wolfram Alpha - Wolfram Alpha 是由 Wolfram Alpha 开发的计算知识引擎（答案引擎）. 它将使用 Wolfram 的突破性算法、知识库和人工智能技术计算出专家级的答案。
  • Yahoo! Search - 一个门户网站，提供搜索、新闻、财经、邮箱等服务。

    • 专业搜索引擎

    特定信息或主题的搜索引擎。

  • 2lingual Search - 双语搜索引擎，同时搜索多个语言的结果。
  • BeVigil - 在移动应用程序中搜索子域、URL、参数等资产。
  • Biznar - 一个针对图书馆、学术机构和研究机构的元搜索引擎，同时搜索多个学术数据库和图书馆目录。
  • CiteSeerX - 专门针对计算机科学领域的学术搜索引擎，提供计算机科学方面的论文、期刊、会议等信息。
  • Criminal IP - 一个网络威胁情报搜索引擎和攻击面管理 (ASM) 平台，用于搜索网络威胁情报、漏洞信息等。
  • Google Custom Search - 谷歌提供的自定义搜索引擎，可以在特定网站、特定领域或特定语言等范围内搜索结果。
  • Harmari (Unified Listings Search) - 专注于在线广告市场监管的搜索引擎，可帮助用户查找和监测在线广告、租赁和短租房屋、二手车和人力资源等信息。
  • Internet Archive - 一个数字档案库，包括网络档案、音乐、电影、图书、软件等多种类型的数字资料。
  • Million Short - 可以排除前一百万个搜索结果，让用户可以发现新的和不常见的网站。
  • WorldWideScience.org - 一个全球科学信息门户，提供全球多种语言的科学文献、数据和专利等信息。
  • Zanran - 一个搜索数据和统计数据的搜索引擎，专注于收集和索引来自公共领域的数据。

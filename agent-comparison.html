💰 Token 与成本 05

这一节我删掉了旧页的 11K / 29K / 11K 和「40% 固定税」。原因很简单：本机没有任何一处测过这三个数，旧页也没写测量方法。留着它们，读者只会照着做决策。

总 Token 的构成公式（这个是确定的）

总 Token = System Prompt + 记忆注入 + Skill 注入 + 当前对话 + Tool 结果 + LLM 输出 ↑ 固定开销 ↑ 记忆系统决定 ↑ Skill 系统决定 ↑ 用户行为决定

公式没错，错的是旧页把"固定开销"直接填了三个拍脑袋的数。真正要算固定开销，得先确定每个 Agent 在你的配置下会注入多少——这是配置相关的量，不是产品的常量。

能确证的三个成本事实

事实数字来源
Anthropic 全系 Prompt Caching 折扣 cache_read = 0.1 × input（缓存读取只要输入价的 10%） 本机模型定价目录：带 cache_read 的 4503 个模型中，比例恰为 0.1 的有 1827 个，是最常见档；Anthropic 全系命中这一档
缓存写入有溢价 Anthropic cache_write 约 1.25 × input 同一份定价目录
OpenClaw 的 Skill 索引成本 约 24 tokens / skill（约 97 字符 ÷ 4 字符/token） OpenClaw 源码的 skills 文档「Token impact」一节；每个文件另有 20,000 字符的 bootstrap 预算

想把「固定开销」测出来，该用什么

DeepSeek Harness 里有一个 token-meter 子系统，记录每次调用的 TokenMeasurement（baseline、surfaceDeltaTokens、totalTokens、surfaceTokens、nodes[]），按路由给不同模型定价。想做固定开销对照，就用同一套任务、同一个模型、只换 Agent，然后读同一个计量口径——这比拍三个数靠谱得多。

方寸智匣已经用上了这套：它的上下文压缩有四种路径，每一种都单独测过耗时和压缩后的 token 数（见下一节）。

⚙️ 执行循环 07

架构决定上限，循环决定日常体感。

Claude Code

用户输入 ↓ System Prompt（CLAUDE.md + memory） ↓ LLM 推理 ↓ Tool 调用 ↓ 结果返回 → 继续推理 → 输出 单线程 · 单会话 · 自动压缩上下文

OpenClaw

消息平台（32 个渠道） ↓ Gateway（路由 + 会话管理） ↓ 五层记忆注入 → LLM 推理 ↓ Skill / Tool 执行 ↓ 响应回平台 → 后台 Dreaming 多平台 · 多会话 · 心跳 · 子代理

Hermes Agent

消息平台 / CLI ↓ Gateway（23 个适配器） ↓ FTS5 检索 + 可选用户建模 ↓ LLM 推理 → Skill/Tool 执行 ↓ 经验提炼 → 自动写新 Skill 学习闭环 · 并行子代理

DeepSeek Harness

用户 / 目标 ↓ 技能注册表（host + 多 scope 分层， 近层覆盖远层） ↓ 工具执行（32 个工具包） ↓ 子代理 / 工作流（可编排） ↓ token-meter 计量 + 审批闸 工具层、权限、沙箱、计量都可替换

方寸智匣

聊天模型 指挥 ↓ DSH 内核（agent-loop / session / session-projection / tools） ↓ 本地模型 + 六类媒体 MCP ↓ 证据与回执（逐字节 SHA-256） 2026-10-07 起停用自研 loop，改用官方内核

实测里的循环特征

安全检查任务 ↓ 18 次工具调用 ├── security_web_browser ×7 ├── security_read_report ×7 ├── security_web_request ×2 ├── security_context ×1 └── security_web_open ×1 ↓ 9 个系统批准框 → 出报告 round 18 · sequence 7857 · 38 条消息

🎯 选型建议 08

按你手上要解决的事选，而不是按功能表选。

你的处境推荐理由
纯写代码、调试、重构Claude Code工具集最稳，出错时你知道问题在哪一层
要接很多聊天平台、想 7×24 小时在OpenClaw32 个渠道 + 心跳 + 子代理，是这五家里最像"常驻助理"的
想让 AI 越用越懂你的工作方式Hermes Agent唯一有"自己长出新技能"闭环的
要跑在本地模型上、且要可复现方寸智匣每一步都有回执和 SHA-256，能离线复跑
想自己搭一套 Agent 内核DeepSeek Harness工具层、审批、沙箱、计量都是可替换部件
数据敏感、完全离线方寸智匣本地模型 + 本地回执，不出网
成本敏感Claude Code缓存读取价 0.1× + 按需加载，两头都省

一句话总结：Claude Code 是最稳的编码刀，OpenClaw 是最广的连接网，Hermes 是唯一会自己长大的那个，DeepSeek Harness 是可以自己拼装的骨架，方寸智匣是把本地模型真跑出结果的那个。记忆和 Skill 从"静态笔记"到"五层自动整合"再到"自学习闭环"，正好是一条进化线。

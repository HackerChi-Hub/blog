注册成功不算成功，模型回答才算

很多免费资源清单停在“网页能打开、按钮能点、密钥能创建”。这只能证明注册流程存在，不能证明密钥有额度、目标模型能调用，更不能证明第三方 Agent 能接入。一次完整验证至少要跨过两道门：先请求模型列表或鉴权接口，再发送最小聊天请求，收到正常生成结果。

这次测试覆盖 OpenRouter、Groq、Mistral、Agnes、Cohere 和 Cloudflare Workers AI。六家都使用账户自己创建的密钥，没有借用公开共享密钥。测试只发送一句极短提示词，把费用和隐私暴露压到最低；记录模型、状态码和响应时间，不把密钥写进截图或公开文件。

⚠️
密钥一旦在聊天、直播、录屏、代码仓库或截图里完整出现，就应视为已经泄露。即使调用仍然成功，也应立刻撤销并重新创建。遮住中间几位不是保护完整明文的补救办法。

“免费”至少有四种，不能放进同一个抽屉

第一种是周期重置型。Cloudflare Workers AI 每天提供 10,000 Neurons 免费额度；OpenRouter 的免费路由会在可用免费模型间动态选择。这类服务适合持续的小流量实验，但模型、吞吐和每日可用量都不是无限承诺。Cloudflare Workers AI 定价说明｜OpenRouter 免费路由说明

第二种是限速型免费套餐。Groq、Mistral 和 Agnes 更接近这种结构：可以取得自己的密钥并持续调用，但每分钟请求、每日 Token、并发、模型名单或账户状态会决定实际容量。它们最适合个人 Agent、自动摘要、原型和备用通道，不适合直接许诺稳定的大规模服务。

第三种是试用与非商用型。Cohere 的试用密钥可以调用模型，却有严格限额，而且官方把试用与生产密钥分开。做个人实验没有问题；一旦接入收费产品，判断标准就不再是“技术上能不能调用”，而是许可和生产条件是否允许。Cohere 试用与生产说明

第四种是一次性赠金型。Deepgram、AssemblyAI 等工具常以注册赠金降低首次体验成本，额度耗尽后不会按月复活。把这种优惠写成“永久免费”，就像把商场试吃当成终身食堂：第一次确实没付钱，经济结构却完全不同。

类型典型代表会不会恢复最大隐患适合用途
周期重置OpenRouter、Cloudflare按日或规则恢复模型池和额度变化长期低频任务
限速套餐Groq、Mistral、Agnes通常持续，但受限风控、地区、并发Agent 与原型
试用密钥Cohere通常不等于生产额度非商用与速率限制学习、评测
一次性赠金Deepgram、AssemblyAI通常不会用完即付费语音项目验证
💡
一个免费入口值不值得收录，至少要写清八项：注册地区、手机号要求、银行卡要求、实名要求、免费额度、重置周期、商用限制、能否被其他 Agent 通过 API 调用。

六家怎么选：不是挑最强，而是匹配任务

如果只想给各种 Agent 找一个 OpenAI 兼容入口，OpenRouter 最省事：一个接口连接多个模型，openrouter/free 不必先押注具体型号。代价是动态路由可能让输出风格、上下文和速度变化，它更像免费模型调度器，而不是一台固定机器。

如果最在意文字响应速度，Groq 值得放在前排；如果想直接调用 Mistral 自家模型，Mistral Studio 的免费实验模式更清晰。两者都适合做高速备用通道，但要给 429、403、模型下架和超时准备回退逻辑。Groq 快速开始｜Mistral 免费模式与密钥

如果想在同一账户继续探索文字、图片和视频，Agnes 的产品组合更有吸引力。但这里必须划一条证据边界：这轮只确认 agnes-2.0-flash 的文字调用成功，网页里出现免费图片或视频模型，不等于它们已经完成同样测试。Agnes Token 计划

如果是学习、分类、检索或企业文本实验，Cohere 可以作为试用选项；商业使用前要重新核对生产密钥与许可。Cloudflare 则最适合已经使用 Workers 的人：账户 ID 和 API 令牌共同组成调用条件，令牌只授予 Workers AI 所需权限，避免把拥有全账户权限的 Global API Key 交给 Agent。

其他路线仍然保留，但把门槛写在名字旁边

只保留“注册就得到 Key、第三方 Agent 能调用”的名单，会错过一些有价值但附带条件的服务。更诚实的做法不是删掉它们，而是把障碍放到同一张表里：读者能立刻知道自己缺的是实名、地区、银行卡，还是一次人工审核。

还有一类应放进“已退役”而不是“免费名单”：GitHub Models 已在 2026 年 7 月 30 日退役。这个变化比新增一家免费平台更有教育意义——入口来自大公司，也不等于永久存在。GitHub 官方退役公告

平台为什么愿意免费：它买的不是善意，是入口

九十年代的浏览器战争里，Netscape 与 Internet Explorer 用免费分发争夺上网入口；共享软件用免费基础功能换传播；今天的 API 免费层也在争夺开发者默认选项。区别是复制一份浏览器几乎没有新增成本，而模型每生成一次都要消耗算力，所以配额就是平台的成本阀门。

免费层让开发者先写下模型名、SDK 和接口地址。等工作流、提示词、数据格式和错误处理围绕它生长，迁移就不再是换一行 URL。平台获得生态、反馈和未来付费用户；用户获得低成本试错，同时背上政策改变、停服和重构的风险。

Pi 日报在 2026 年 7 月连续记录过 OpenRouter 免费模型的增加与替换，也记录过开发者用自有 API Key 重做付费工具的案例。两个信号放在一起看：免费资源确实能生产真实价值，但它更像流动的供应池，不像永久安装在家里的软件。

公开共享 Key 看似把注册成本降到了零，最后往往落入“公地悲剧”：使用者越多，滥用越快，额度越早耗尽，密钥越容易被封；真正的所有者还可能收到异常账单。自己注册、自己限权、自己轮换，才是能交给 Agent 的最低安全标准。

一张决策图：先问限制，再问模型

在真正的 Agent 配置里，再加四个保护：本地限速、超时、熔断和备用供应商。把模型名、基础地址和密钥放进独立配置，业务逻辑不要直接绑定单家服务。这样某个免费模型下架时，损失是一张配置表，不是一整套程序。

📌
最省钱的结论不是“找到一个永远免费的 Key”，而是建立一个可验证、可替换的免费供应池。免费额度负责试错和低频任务，重要业务保留预算与迁移出口；七天后、三十天后再复测一次，才能看出谁只是短期优惠，谁能成为稳定工具。

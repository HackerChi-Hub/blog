1.7.0：匯出浮水印換成自己的署名

課程、示範與審片輸出後，角落要顯示什麼，現在可以自己選。匯出浮水印預設為「黑粉录屏」，可直接關閉；展開自訂區後，可改成頻道名、網址、審片提示或本機標誌圖片。

文字與PNG／JPEG／WebP圖片可單獨或組合使用，保留圖片比例，提供四角及居中五種位置、大小和不透明度。示意圖協助選位置，實際文字隨背景明暗調整。實際匯出時儲存設定，MP4與GIF共用原生疊加路徑；一般編輯預覽不加此層，也不刪除工程原有文字或標誌。

1.6.9：先看成片，再改成自己的講解

本機編排擴為八類：來源證據、原理過程、角色講解、前後對比、數據對比、重點清單、時間脈絡、結構拆解。在「製作動畫 → 本機編排」先播放真實範例，再填本期文字、數據、圖片與節拍，產生後仍能編輯圖層與關鍵影格。固定框架在本機執行，無需請求大型模型。

紙白信號與黑粉深色兩套配色共16個12秒動態範例。以下是紙白信號八類的96秒完整靜音合輯，展示可重用的結構及動作。

單獨開啟完整靜音合輯

角色使用同一人物的六張完整姿態插畫，身分、服裝和比例一致。統一講解圖作為預設，各階段可單獨配圖；未設定時沿用統一圖，保留原始縱橫比例。「恢復沿用」只清除目前階段的綁定。完整圖片切換適合觀察、指向與回應，不是自由人物表演。

窄檢查器按自身寬度排列，通常顯示兩列階段卡，文字不擠成直排，套用按鈕不懸浮遮住設定。原生輸出補齊WebP解碼，避免瀏覽器可見、匯出缺圖。

16份1920×1080、30幀、12秒輸出完整解碼，六階段已逐處抽幀。獨立工作室的系統選圖、第四階段套用、磁碟讀回及約6.3秒跳轉通過，只修改選中階段，復原後回到原編排。4650項測試通過、2項略過。範例靜音，未完成主觀聽審；實體錄製、所有跳轉位置與其他系統未在本輪重測。Windows與Linux現已透過本機建置補齊1.7.0，包含上述本地編排與階段配圖；桌面操作不從Mac實測推斷通過。

Mac 1.6.9已完成映像完整性、嚴格簽署及609個檔案與連結的一致性核對，並從正式安裝目錄的原生合成器重新匯出階段配圖、數據對比兩份1080p30樣片，完整解碼通過。安裝版工作室已啟動，但系統擷取畫面的工具隨後連續錯誤，最後的介面點擊與連續播放驗收尚未完成；前述介面檢查來自獨立開發工作室。

1.6.8：改內容、調節拍，本機產生講解動畫

Mac新增「本機編排」：開啟專案，在「製作動畫」選擇來源證據、原理過程或角色講解，填寫內容與動作時刻，即可產生原生動畫，無需模型。它適合反覆更換內容的講解段落，沿用排版並修改本期原圖、步驟與動作。

來源證據保存本機原圖、來源名稱、地址及核對日期，依時刻出現、聚焦與保留重點。原理過程支援兩到五步，可逐項調整節拍並選擇工程既有音效。角色提供看向、指向、接物、放下、確認與收勢等預設動作。這些任務由本機腳本編排，不執行模型產生的程式；自由設計仍可使用原有模型創作。

動畫「內容」頁可直接改普通文字與本機圖片，也可修改編排的來源、步驟、配色及事件時間。動作與聲音共用節拍。動畫可固定在專案時間尺或跟隨完整涵蓋它的一個主錄影片段，隨移動、分割、裁短及刪除調整。連續相容且不重疊的編排優先共軌，不跨中間畫面軌強行合併。

內容與節拍確定後再精調圖層：重新編排會重算受控圖層，保留人工新增圖層，鎖定受控層則拒絕覆蓋。它不是通用角色骨架或任意長故事產生器，獨立旁白與輔助影片的來源綁定不在本輪範圍。

開發版實際點擊產生、修改標題與4.25秒節拍，儲存並切換專案後重開，修改保留。兩份不同內容的24秒工程及12秒角色工程完成跳轉與連續播放，三部1920×1080、30幀原生匯出完整解碼通過。4637項測試通過、2項跳過。音量檢查通過，主觀聽審未完成；其他系統與實體錄製未重測。Windows與Linux1.7.0已包含上述功能。

1.6.7：整片包裝，選片段與改版式更直接

Mac更新至1.6.7。片段選擇合為一組，卡片顯示縮圖、標題、版式與時間，再用「本段版式」修改目前片段。參數並排，靜態與動態範例共用預覽區。一般四段設定在1280×720與1024×768可完整顯示，小視窗及更多片段可捲動。

十套名稱統一四字，包含紙白橙調、暖霧光影、紅色海報、幾何構成；舊專案ID、配色、動效與聲音維持相容。Windows與Linux1.7.0已包含上述緊湊介面。

本輪4615項測試通過、2項跳過，應用與測試型別檢查通過。Mac安裝目錄570個檔案與連結和安裝鏡像逐一相符，嚴格簽章通過。安裝版讀取獨立四段專案，重新匯出27.4秒、1920×1080、30幀、822幀影片，音畫完整解碼通過；素材沿用已有成果，不冒充重新產生。正式應用啟動與工作室開啟正常，之後系統取屏錯誤，作者明確改為手動測試後繼續發行；本輪桌面點擊產生與跳轉互動不記為代理驗證通過。

1.6.6：Windows 與 Linux 補齊整片包裝

Windows、Linux 本機建置至 1.6.6，包含十套整片包裝、四十種版面。修復產生時呼叫未附帶的 libx264 的問題，改用隨包 OpenH264，不需要額外安裝編碼器。Mac現提供1.7.2。

Windows 與 Linux 渲染驗證各用合成素材產生四種版面，共 16 秒、480 幀，畫面與主題聲音完整解碼通過。Windows 包內 331 個包裝資源與原始碼逐一核對；Ubuntu deb 安裝及檔案校驗通過。此項不替代完整桌面錄製或所有裝置驗證。

1.6.5：為一期錄屏選一套完整包裝

片頭、清單與資料圖各自好看，放在一起卻未必協調。1.6.5加入「整片包裝」，先選整套設計，再填入本期多個段落，讓排版、配色、動效與聲音沿用同一套規則。

開啟專案，在AI面板選擇「整片包裝」。紙白信號橙、貼紙波普、黑白薄荷、暖霧、便箋復盤、孔版印刷、昭和海報、復古旭日、彩卡拼貼、包豪斯幾何，共十套；每套包含開場、清單、聚焦、數字四種版面，提供真實縮圖和動態範例。共用編輯視窗依版面顯示必要欄位，淺深色清晰顯示，產生按鈕與進度固定在底欄。

每組1至12段，每段4至30秒。填入內容與時間，聚焦版面再選取工程中的影片截圖，便可在本機產生並整組加入時間軸；不呼叫大模型、不上傳錄屏。主題音效預設開啟、配樂預設關閉，保留原口播。已儲存設定可修改並重新產生以替換原組；人工移動、裁切或鎖定過的組會拒絕覆蓋。

實際錄屏四段27.4秒合輯完成產生、加入、替換、跳轉、連續播放、儲存重開與1920×1080、30幀匯出。十套預設配色、四十版面完整解碼通過，音訊無削波，四段主題聲音無時間重疊；作者確認實際合輯聽感正常。其餘配色未逐一匯出，其他九套未分別記錄主觀聽審。

產生片段可剪輯，內部圖層暫不能逐層編輯；修改內容需改設定後重新產生。畫面與聲音分軌，移動時一起框選。Mac實際錄屏專項沿用1.6.5紀錄，Windows／Linux整片包裝產生驗證範圍見本頁1.6.6說明。

此前1.6.4：游標小幅移動，畫面保持穩定

錄製軟體操作時，游標常常只是在按鈕附近稍微移動。1.6.4為縮放片段加入「穩重講解」與「靈敏示範」兩種運鏡，分別適合文件講解與跨控制項操作。

選取時間軸的縮放片段，在右側「縮放 → 對焦模式」選擇樣式。安全區像鏡頭裡預留的活動範圍：游標在區內移動時保持構圖，越過邊界後才平滑跟隨；縮小退出時保持最後焦點。連續點擊依時間與位置組成操作段，減少同一選單操作反覆縮放。

新自動縮放預設採用穩重講解，舊專案保留原有跟隨；游標圖示的平滑與新鏡頭分開控制。需要對應錄屏的游標軌跡，外部影片可以使用手動焦點。

同一真實錄屏及游標軌跡組成三模式48秒工程，獨立Mac工作室完成模式切換、儲存、連續播放及跳轉；兩次回到19.94秒的預覽像素一致。1920×1080、30幀、1440幀原生匯出與完整解碼通過，並修復預覽初始化畫布路徑。本輪未重測其他系統及全部錄製裝置。

正式Mac安裝版再次讀回三種運鏡設定，48秒匯出完整解碼通過；介面檢查了20秒跳轉後的連續播放與35秒跳轉。安裝包公開上傳後重新下載，校驗值與本機一致，較1.6.3僅增加約14 KB。Windows 與 Linux 現已透過本機和 WSL 本地建置補齊 1.6.4。Windows 包完成三種運鏡模式的合成範例原生匯出及完整解碼專項，Ubuntu deb 安裝校驗通過。對應系統的桌面錄製全流程仍需實機驗證。

先講一件讓我背脊發涼的事。我替自己寫的錄屏軟體做了自動打碼——辨識畫面裡的電子郵件、金鑰這些東西，蓋上馬賽克。功能做完，單元測試全部通過：打碼框的位置算得準，靜止畫面上看也嚴絲合縫。

然後我把成片匯出來，從頭到尾看了一遍。**畫面放大的那幾秒，馬賽克沒跟上，電子郵件和一串 sk- 開頭的金鑰清清楚楚地露在螢幕上。**直式改版的裁切裡也露了一次。單元測試測的是「打碼框的座標對不對」，而我真正要的是「成片裡認不出敏感資訊」——這兩件事不是一回事，中間隔著放大、傾斜、裁切和編碼。

從那天起，我替這個軟體加了一道別的錄屏工具幾乎沒有的東西：匯出之後，回讀成片本身做一次體檢，用文字辨識一格一格看過去，確認該蓋住的確實蓋住了。這段記錄寫於 1.0.2 時期；目前版本見上方。

順便聊聊錄屏工具這門生意的錢從哪裡來，這決定了它們把力氣花在哪。常見的做法是：免費版幫你加浮水印或限制長度，把「匯出」做成收費關卡；或者乾脆做成雲端服務，你把螢幕內容傳上去，按儲存和匯出計費。螢幕錄影是隱私濃度最高的一類素材——裡面有你的電子郵件、路徑、token、沒關掉的聊天視窗，受益的是拿走這些素材做儲存和轉檔生意的一方，代價落在上傳的人身上。這套劇本在桌面軟體裡演過很多次：買斷版停止更新，功能一點一點搬進訂閱。

我做黑粉錄屏圖什麼？老實說：**我自己每週要出片，錄屏是主力素材，而我不想把螢幕內容交給任何伺服器。**它沒有訂閱、沒有雲端、不賣儲存空間，所以也沒有靠你賺錢的路徑；維護成本落在我自己身上。1.0.2 起匯出完成時會附一張贊助碼，給願意的人留個出口，贊助與否功能完全一樣。你可以據此判斷：它不會為了賺你的錢變差，但也可能因為我顧不上而停止更新。

🎥 錄製：先把「錄什麼」變簡單

  • 整個螢幕、某個視窗，或者手動框選任意區域——框選時點一下視窗就直接取得它的範圍，不用自己對邊；可以鎖定 16:9、9:16、1:1、4:3，錄直式內容不必事後再裁。框選支援 macOS 和 Windows。
  • 攝影機、麥克風、系統聲音一起錄，滑鼠軌跡同步記下，剪輯時依滑鼠停留的位置自動建議平滑放大。攝影機依裝置支援的最高畫質錄製。
  • 麥克風、攝影機、錄製範圍和攝影機外觀能存成多套「錄製配置」，一鍵切換。

以前的錄屏軟體大多只管「錄」，剪輯要另開一個軟體，匯出一次、匯入一次，畫質掉兩次。所以這個軟體從一開始就是錄 + 剪一體，錄完直接進時間軸，中間不多做一次編碼。

✂️ 剪輯時間軸：照達文西的樣子排

  • 字幕、標註、縮放、變速、剪切、V1 影片（上方可以再加影片軌）、A1 原聲，A2 起是配音和音樂；軌道頭寫明名稱和條目數，能鎖定、隱藏、靜音、調整順序。
  • 條目直接寫出內容：標註文字、範本名、打碼類別、放大倍數、剪掉的長度、字幕句子，不用一個個點開看。
  • 配音和音樂的波形依畫面上看得見的那一段、以裝置像素繪製，放得越大越清楚。
  • 按 M 打標記，標記能直接複製成影片簡介裡的章節時間碼。A/B 選取與刀片、Cmd+B 分割、J/K/L 播放、I/O 入出點，都是剪過片的人熟悉的按鍵。

🧱 多軌與畫布直接編輯

  • 一次匯入多個影片和音訊；影片軌道不設數量上限，上層的畫面蓋住下層，聲音疊加混音。拖片段、拖邊緣就能排列和裁切，按住 Shift 精調，方向鍵逐格。
  • 暫停時直接在預覽裡點選：錄屏畫面和攝影機可以移動、等比縮放；字幕、文字、圖片、箭頭、模糊框和範本都能直接拖、直接調整大小。
  • 全螢幕預覽（F 進入、Esc 離開）；複雜專案可以把預覽解析度降到 1/2、1/4 保持流暢，匯出一律是完整解析度。

🎭 畫面與攝影機

  • 子母畫面、左右分割、上下分割，分割畫面一鍵對調位置；螢幕永遠維持原比例完整顯示。
  • 去背邊緣依攝影機原畫面的真實輪廓放大（macOS）：手指、眼鏡腳、肩膀的輪廓是清楚的，不再是一圈模糊的邊；背景可以是模糊、圖片、顏色或漸層。
  • 子母畫面裡螢幕和攝影機互相讓位：螢幕放大時攝影機縮到角落，攝影機放大時螢幕縮小讓開；縮小的攝影機依像素涵蓋範圍取樣，不閃也不糊。

  • 本機辨識電子郵件、手機號碼、身分證號、銀行卡號、金鑰和你自訂的關鍵字（自動辨識目前是 macOS），身分證號和銀行卡號先做校驗，誤報少。

  • 匯出時如果你暫時關掉了標註或縮放軌道，打碼軌道始終保留並提示你——這條是故意不讓你關的。

🩺 成片體檢：不信過程，只認成品

回到開頭那個坑。教訓是：**過程裡的檢查再怎麼通過，也不等於成品是對的。**所以匯出完成後可以一鍵對成片本身做體檢，檢查項目都落在「成品」上：

  • 響度與真峰值：給出輸出音量建議，不用自己用耳朵猜
  • 無聲段落和黑畫面段落：一段一段標出來
  • 畫面卡住：成片停住了但原片還在動——這是匯出出錯最典型的樣子
  • 成片比時間軸短：片段超出素材長度，直接定位到素材用完的那一刻
  • 字幕和標題放不下：被裁掉或超出畫面的都標出來
  • 文字辨識回讀畫面：逐格確認敏感資訊沒有露出（目前 macOS）

下面這組數字來自 0.4.13 安裝版的一次實測紀錄（透過軟體自己的介面在驗收專案上匯出 1280×720/30fps 再體檢，數字是程式寫下的，不是我手抄的）：

建議 最後那一行才是重點。一個檢查器回報「沒發現問題」，有兩種可能：真的沒問題，或者檢查器根本沒在工作。分不清這兩者，它就一點用都沒有。所以我每次都要拿一份故意去掉打碼的成片給它——它必須把電子郵件和金鑰抓出來，抓到了，它在正常成片上說的「0 項問題」才值得信。

體檢發現的問題可以一鍵標到時間軸上，按 Shift+↓ 一個個跳過去修改。

🤖 AI：自備你的，不替你選

AI 這部分我的選擇是不綁定：不內建模型、不代收 API 費用、不替你決定用誰。你已經登入了 Codex 訂閱就直接沿用（不必填金鑰），想全部在本機就接方寸智匣 LocalBrain。69 個工具涵蓋剪輯、聲音、字幕、轉場、打碼、放大、標記點、逐片段特效、視覺化範本、直式改版、匯出和體檢——編輯器裡能手動做的，AI 都有對應的工具；另外還有 12 個一鍵範本，例如「壓縮停頓」「去除口頭禪」「刪除重複與重錄」「發布前體檢」。外部 AI 也能透過 MCP 介面呼叫同一套工具（加上讀取、儲存、復原、重做共 73 個）。

上一次我對「AI 剪輯」心動是那波一鍵成片，示範驚豔，真的放進出片流程就留不下來——因為它替你做完，而你只能全盤接受或者推倒重來。所以這裡的 AI 是在你的時間軸上動手，每一步都變成可復原的編輯，你隨時能接手。

🗂 專案、修改記錄與儲存

  • 每次修改立即寫入磁碟，另外依時間保存整個專案的版本（預設每 5 分鐘、只在有改動時），每個版本寫明來由和變化，隨時退回，退回本身也能復原。
  • 專案能另存到任意位置、從任意位置直接開啟；新建專案的預設資料夾可以放在外接硬碟。

1.0.1 新加的「儲存位置與清理」是我自己被系統碟空間逼出來的：

  • 錄製資料夾能換到別處，已有的錄製一起搬過去，所有專案和修改記錄裡的參照自動改好；先複製、核對，最後才刪原檔。剛停止的錄製還要幾秒收尾，這時去搬會請你稍等——不會只搬走半個錄製；搬過去的檔案保留原本的修改日期。
  • 快取也能換位置，舊快取直接刪除、新位置依需要重新產生；每類快取分別列出大小，單獨清或一鍵全清。錄製和專案永遠不在清理範圍裡。
  • 順手修了一個老毛病：以前關掉軟體後，人聲隔離有時會留在背景繼續佔滿一個 CPU 核心、跑到半小時逾時，再開啟時就和新的搶資源。現在結束時背景程序一併結束。

☕ 1.0.2：匯出完成時附一張贊助碼

軟體不收費、不放廣告，1.0.2 在匯出成功的面板裡、「已儲存至」正下方附了一張微信贊助碼，配一句「不取分文無廣告，但求一盞謝知音」。放在這裡，是因為這一刻你剛拿到成片，而不是正要開始工作。

  • 安裝滿 3 天才出現，安裝時間以軟體資料夾的建立時間計算，升級不重新計時；之後每次匯出成功都會出現，但一天最多一次，按日曆日計算。
  • 錄製進行中絕不出現：錄屏時跳出來的任何東西，都會被錄進你的影片。每次匯出完成，它先問一句「現在有沒有在錄」，問不到就當作在錄，寧可這次不出現。
  • 只在中文介面出現；它沒有按鈕，也不擋任何操作，贊助與否功能完全一樣。
  • 這張碼是安裝程式裡的一張圖，顯示它不連網，出現和開啟都不做統計。想主動找它，左上角「黑粉录屏」選單點「支持作者」。

⚠️ 它目前的限制

  • 沒有正式簽署：Mac 版用我自己的憑證簽署、未經 Apple 公證；Windows 未做程式碼簽署，第一次執行會跳出 SmartScreen；Linux 也未簽署。
  • 平台能力不同：Mac為1.7.2，Windows與Linux為1.7.2；人聲隔離、自動打碼中的敏感資訊辨識及成片文字回讀目前僅 macOS 提供。框選時「點視窗取範圍」支援 macOS 與 Windows。Windows／Linux 的桌面互動仍需在各自系統實機驗證。
  • Linux 相依套件多：錄屏全部經由 xdg-desktop-portal，還需要 Vulkan 驅動和對應桌面的 portal 後端。

🧭 我的判斷

如果你也做教學、評測、軟體示範這類內容，錄屏真正的成本從來不在錄那十分鐘，而在後面：刪停頓、打碼、轉直式、檢查有沒有出包。這個軟體的設計重心全部放在「錄完之後」，包括那道聽起來有點笨的體檢——匯出完再看一遍成片。

笨方法有笨方法的好處：它不相信我自己寫的任何一個中間步驟，只認最後那個檔案。經歷過「單元測試全部通過但電子郵件露出來」之後，我覺得這個不信任是值得的。這次替這篇文章拍截圖，我又被自己的軟體上了一課：拍圖時看出三個問題——切分片段會丟掉後面的音樂、捲動頁面上的打碼框太大、靜音被轉寫成「[BLANK_AUDIO]」這樣的英文標記——都是測試沒抓到、畫面一看就明白的。修好了才出 1.0.1。1.0.2 加贊助碼時又來了一次：我寫的 14 項實機檢查全部通過，截圖一看，贊助條卡在匯出對話框的底邊，只露出半行字，按鈕在底邊以下，點開的碼也落在看不見的地方。檢查問的是「它在不在」，用的人要的是「看不看得見」。

摘要：1.0.2 時期的設計總結 黑粉錄屏是我自己在用的錄屏 + 剪輯軟體。這段歷史記錄講的是當時的 Mac 版：本機辨識敏感資訊、讓馬賽克跟著放大與裁切移動，並在匯出後回讀成片。當前各平台版本、下載與驗收範圍見本文開頭。

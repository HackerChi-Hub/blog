## 本地预览与上线

`npm run community:preview`默认启动4191端口的正式导出预览；本轮最终验收使用4192，避免打断已有预览。只代理公开留言GET，所有写请求都在本机拒绝，不会向官网发测试留言。验证码受正式域名及网络环境约束，本机不能完成正式提交验收，不能把本地无法提交当作正式服务故障。

上线需先展示关键预览，确认后由既有blog-push发布；留言Worker的最近记录排序需一并部署。原有鉴权、验证码、身份保护、限流与数据表不变。线上再验证茶馆分类、来源传递、真实留言及站长回复，不用本地测试数据库冒充正式验收。
